CAPSULE FRAME VECTOR CROSS-CHECK

Purpose

The C sharp source is compiled by PowerShell Add-Type, matching the existing Windows
confinement and native preflight drivers. Its vectors are generated by the
independent C sharp codec and carry producer=independent-csharp. The checked-in JSON
file is a placeholder until a Windows CI run generates and reviews the vectors.

Windows CI sequence

1. Compile the C sharp source with:

   pwsh -NoProfile -File kit/confinement/capsule_frame.ps1 -Mode compile

2. Generate a temporary fixture from that C sharp source, then point the Python test
   at it. The generator emits one canonical ASCII JSON line:

   $env:KD_CAPSULE_FRAME_GENERATED = Join-Path $env:RUNNER_TEMP 'capsule_frame_vectors.json'
   & kit/confinement/capsule_frame.ps1 -Mode vectors | Set-Content -LiteralPath $env:KD_CAPSULE_FRAME_GENERATED -Encoding ascii
   if ($LASTEXITCODE -ne 0) { exit 1 }
   python -B kit/confinement/test_capsule_frame_vectors.py
   if ($LASTEXITCODE -ne 0) { exit 1 }

3. Review the generated data and replace the checked-in pending fixture with
   that output. Later CI runs should compare the generated JSON object to the
   checked-in fixture before running the Python unittest against the fixture.
   When the checked-in file is ready, the Python test requires the generated
   JSON object to equal the checked-in object. It compares the key record,
   header, deterministic CBOR,
   header digest, HKDF, global nonces, and AAD values with the Python codec.
   It also checks that C sharp GCM pair digests, tags, manifest-region digest, and
   full-capsule length and digest are present in the independently generated
   record. The Python framing codec has no AES-GCM provider, so this unittest
   does not recompute the C sharp GCM pairs or full-capsule digest. Those fields
   still need the independent primitive oracle and review required by the
   approved design.

Vector properties

The generator uses fixed test-only identity values, the published P-256 base
point, a fixed 32-byte synthetic shared X value, fixed salt and nonce prefix,
a deterministic manifest with one regular-file entry, zero encrypted padding,
and a fixed trailer.
It encrypts all 272 chunks with one key and the global indices 0 through 271.
It reports SHA-256 of selected full ciphertext chunks and their tags instead
of embedding megabytes of ciphertext. The full 286261248-byte capsule is hashed
in chunk order without writing the body to disk. This vector source does not
perform the persisted CNG leading-zero ECDH proof; that remains a separate
Windows interoperability gate in the approved design.

The Python provisional choice in kit/confinement/capsule_frame.py under
PROVISIONAL_CHOICES records destination aliases as NFC plus casefolding. The C
sharp codec normalizes to NFC and uses invariant lowercase with common full-fold
expansions in its alias helper. The design leaves the exact Windows equivalence
algorithm unspecified, so the C sharp and Python Unicode tables may differ on
less common characters. Independent review should include Unicode alias cases
before treating protocol bytes as frozen.

Workflow registration

This lane adds no workflow. The coordinator must register a workflow kind in
the repository policy before adding these Windows compile and vector steps to
GitHub Actions.
